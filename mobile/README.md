ابدأ من [SETUP.md](SETUP.md): يشرح إعداد PHP 8.3 وقاعدة اختبار محلية، تشغيل API، إعداد عنوان API، بناء Android والتصدير بأمان.

عنوان API الافتراضي في `lib/src/api_config.dart` هو `https://sarehny.com/api/v1/`، ويمكن تغييره وقت البناء إلى HTTPS staging عبر `API_BASE_URL`. GitHub Actions يشغّل تحليل Flutter والاختبارات ويبني ويرفع APK أولًا؛ لا يشغّل محاكيًا على الإنتاج، ولا يرسل بيانات اعتماد. فحص مسارات PHP الحية قراءةً فقط اختياري في التشغيل اليدوي، واختبار Android end-to-end متاح لبيئة staging معزولة وأسرار اختبار منفصلة. لا يرفع Workflow ملفات PHP ولا يغيّر Hostinger أو قاعدة البيانات. صفحات الموقع الأصلية تُتاح داخل التطبيق عبر Android WebView مقيد بالأصل نفسه وتستخدم جلسة PHP المنقولة بأمان؛ الوظائف الأصلية التي لا يملك التطبيق لها endpoint تبقى مُدارة من الموقع نفسه. راجع [`SETUP.md`](SETUP.md) لحدود الاختبار والتشغيل.
