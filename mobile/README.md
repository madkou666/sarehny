ابدأ من [SETUP.md](SETUP.md): يشرح إعداد PHP 8.3 وقاعدة اختبار محلية، تشغيل API، إعداد عنوان API، بناء Android والتصدير بأمان.

عنوان API الافتراضي في `lib/src/api_config.dart` هو `https://sarehny.com/api/v1/`، ويمكن تغييره وقت البناء إلى HTTPS staging عبر `API_BASE_URL`. GitHub Actions يشغّل تحليل Flutter والاختبارات ويبني ويرفع APK أولًا؛ لا يشغّل محاكيًا على الإنتاج، ولا يرسل بيانات اعتماد. فحص مسارات PHP الحية قراءةً فقط اختياري في التشغيل اليدوي، واختبار Android end-to-end متاح لبيئة staging معزولة وأسرار اختبار منفصلة. لا يرفع Workflow ملفات PHP ولا يغيّر Hostinger أو قاعدة البيانات. الصفحات العامة المدعومة تُعرض داخل شاشات Flutter أصلية وتقرأ بياناتها عبر PHP API؛ لا يحتوي Android على WebView. الميزات التي لا تملك واجهات API أصلية موثقة تظهر بوضوح كغير مكتملة بدل فتح صفحة الموقع. راجع [`SETUP.md`](SETUP.md) لحدود الاختبار والتشغيل.
